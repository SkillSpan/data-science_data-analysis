# How the SkillSpan Journey Works

A typical SkillSpan learner journey follows these connected stages:

1. Register, verify the account, and complete the mandatory learner profile.
2. Complete the Post-Profile Baseline Skill Assessment after mandatory profile fields are complete.
3. Build the Skill Matrix from assessment results and approved skill evidence.
4. Select or compare approved target career roles.
5. Calculate role-specific skill gaps, confidence, and Readiness Score.
6. Generate the personalized Career Roadmap, approved resources, and Next Best Action.
7. Discover eligible projects and receive explainable project recommendations.
8. Participate in real or simulated project work using controlled milestones and versioned submissions.
9. Receive automated completeness feedback followed by the required authorized human evaluation.
10. Add verified outcomes to the Digital Professional Record and become discoverable through consent-aware Talent Discovery where permitted.

SkillSpan guidance supports this journey, but authoritative user records, permissions, project states, and final transactional decisions remain controlled by the Laravel backend.
